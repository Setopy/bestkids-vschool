∑ Mathematics · Week 6

Cryptarithms

The big questionIn the sum SEND + MORE = MONEY every letter hides a different digit, and there is exactly one solution. Nobody gives you a single number. How can pure logic find all eight digits?

By the end of this lesson you will be able to

  1. State the rules of a cryptarithm.
  2. Use carries, place value and odd-even reasoning to deduce digits.
  3. Organise a search so that no case is missed.
  4. Prove that a solution is the only one.

1The rules of the game

A cryptarithm is an arithmetic sum in which digits have been replaced by letters.

  • Each letter stands for one digit from 0 to 9.
  • The same letter is always the same digit.
  • Different letters are different digits.
  • The first letter of a number is never 0.

To solve one is to deduce: to reach conclusions that must be true. Guessing is allowed only when you have narrowed the choices and test each one in an orderly way.

2The detective's toolkit

ClueWhat it tells you
The answer has one more digit than the numbers addedIts first digit is a carry. Adding two numbers, that carry is 1.
A column shows X + X = XX is 0 (or X is 9 with a carry coming in).
A column shows X + Y = XY is 0 with no carry in, or Y is 9 with a carry in.
A column is X + XThe result is even, unless a carry of 1 came in.
A letter leads a numberIt is not 0.

Always start where you know the most. Often that is the far-left column (a forced carry) or the units column (no carry can come in).

3Writing a proof

A scholar's solution does not just show digits that work. It shows why no other digits can. Write each deduction on its own line with its reason. When you must try cases, list them all and cross out each one that fails.

Worked examples

Cover the steps. Predict each line before you read it.

Example 1

Solve TO + GO = OUT.

  1. The answer has three digits and the numbers added have two, so the first digit of OUT is a carry: O = 1.
  2. Units column: O + O = 1 + 1 = 2, so T = 2 with no carry.
  3. Tens column: T + G = 2 + G must give U and carry 1, so 2 + G = 10 + U.
  4. G = 8 gives U = 0. G = 9 gives U = 1, but 1 is already O. So G = 8 and U = 0.
  5. Check: 21 + 81 = 102. ✓

Answer: T = 2, O = 1, G = 8, U = 0, and it is the only solution.

Example 2

Solve ME + ME = BEE.

  1. The answer has an extra digit, so B = 1.
  2. Units column: E + E ends in E. Only 0 works, since 0 + 0 = 0. So E = 0, with no carry.
  3. Tens column: M + M must equal 10, to give E = 0 and carry 1. So M = 5.
  4. Check: 50 + 50 = 100. ✓

Answer: M = 5, E = 0, B = 1

Example 3

Find the missing digits: 3▢ × 7 = 2▢6.

  1. The units digit of the answer is 6. Which digit times 7 ends in 6? Only 8, since 8 × 7 = 56.
  2. So the number is 38. Compute 38 × 7 = 266.
  3. The answer fits the pattern 2▢6. ✓

Answer: 38 × 7 = 266

Hands-on: Code-Maker, Code-Breaker

You need: paper, pencil, a partner

  1. Write a simple true sum, such as 47 + 35 = 82.
  2. Replace each digit with a letter, keeping equal digits as equal letters. Try to make real words if you can.
  3. Before handing it over, solve your own puzzle. Does it have exactly one solution? If it has several, change it.
  4. Swap puzzles. The solver must write a reason for every digit.
  5. Score one point for a correct solution and a second point for proving it is the only one.

Practice

Write your full working in your notebook before opening an answer.

  1. Solve A + A + A = BA.

    Answer and why

    A = 5, B = 1 (5 + 5 + 5 = 15)

    WhyThree times A must end in A. Testing 1 to 9, only 5 works: 15 ends in 5. (A = 0 would give 0, a one-digit answer.)

  2. Solve AB + A = BCC.

    Answer and why

    A = 9, B = 1, C = 0 (91 + 9 = 100)

    WhyA two-digit number plus one digit is at most 108, so B = 1 and C = 0, making the answer 100. Then A1 + A = 100 gives 11 × A = 99, so A = 9.

  3. Find every solution of A × A = BA.

    Answer and why

    A = 5, B = 2 and A = 6, B = 3

    WhyA digit whose square ends in itself is 0, 1, 5 or 6. Only 5 × 5 = 25 and 6 × 6 = 36 give two-digit answers.

  4. Solve ON + ON + ON + ON = GO.

    Answer and why

    O = 2, N = 3, G = 9 (23 × 4 = 92)

    WhyThe answer has two digits, so ON is at most 24, and O is 1 or 2. Four times any number is even, so O = 2. Then 4 × N ends in 2, so N is 3 or 8, and only 23 is small enough.

  5. In a cryptarithm a column reads P + Q = P, and no carry comes into the column. What is Q?

    Answer and why

    Q = 0

    WhyAdding Q changes nothing, and without a carry coming in only zero does that.

  6. Find the missing digits: ▢7 + 4▢ = 95.

    Answer and why

    47 + 48 = 95

    WhyUnits: 7 plus what ends in 5? 8, giving 15 and a carry of 1. Tens: the missing digit plus 4 plus 1 equals 9, so it is 4.

★ Scholar's challenge

Solve SEND + MORE = MONEY. Start by finding M, then O, then S.

Answer and why

9567 + 1085 = 10652, so S = 9, E = 5, N = 6, D = 7, M = 1, O = 0, R = 8, Y = 2

WhyM is a carry, so M = 1. In the thousands column S + 1 (plus a possible carry) must reach at least 10, so S is 8 or 9 and O is 0 or 1. O cannot be 1, so O = 0. If the hundreds column carried, E would have to be 9 and N would be 0, which is taken, so it does not carry and S = 9. In the hundreds column E + 0 gives N, and E and N differ, so a carry came in: N = E + 1. The tens column then forces R = 8 with a carry from the units, and D + E = 10 + Y. Testing the digits still free gives E = 5, N = 6, D = 7, Y = 2.

Words to own

Cryptarithm
A sum in which letters stand for digits.
Deduce
To reach a conclusion that must follow from what is known.
Carry
A digit moved to the next column when a column's total is ten or more.
Case
One of the possibilities examined separately in a proof.
Unique
Being the only one.

Socratic table talk

Discuss aloud. There is no answer key: defend your thinking with reasons.

  • What is the difference between finding an answer and proving it is the only answer?
  • A detective and a mathematician both deduce. How are their kinds of certainty different?
  • Is trying every possibility a form of reasoning, or only hard work? When is it the right method?
